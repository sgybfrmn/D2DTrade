## QUICK TROUBLESHOOTING GUIDE

### "My dashboard won't load"
1. Check browser console (F12)
2. Verify API URL in environment variables
3. Ensure backend is deployed
4. Restart backend locally if testing

### "AI isn't generating content"
1. Check Claude API key is valid
2. Visit: https://console.anthropic.com/account/usage
3. Verify you have tokens remaining
4. Check error logs

### "I'm not getting traffic"
1. You need to post MORE (5-10/day minimum)
2. Post to RIGHT communities (r/stocks, r/daytrading)
3. Engage AUTHENTICALLY (reply to comments)
4. Build EMAIL LIST (most valuable)

### "Revenue is too low"
1. More traffic = more earnings (post more)
2. Add email sponsorships (build list first)
3. Get paid partnerships (network with brands)
4. Optimize conversion funnel (track metrics)

### "Affiliate links aren't converting"
1. Verify referral codes are correct
2. Test links in incognito window
3. Check if platform is down (check Twitter)
4. Add more context/education around offer
